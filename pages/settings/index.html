基础

控制哪些消息会自动转成图片。

配合 meme_manager 使用：混合发送的图片会进入卡片，待发表的独立表情也可并入。

卡片外观

默认 720px 宽、28px 正文字号，手机端不用放大也能读清。

昼夜主题

按 IANA 时区和日间区间自动切换；图片不会改变主题。

页眉图片

横屏图片 API 会按配置缓存并自动回退到渐变主题。自己的横屏 API / Docker 说明

页脚图片

页脚默认显示机器人昵称和头像；图片源可以单独设置。

内容与安全

控制 HTML/Markdown 识别、公式、正文图片和远程图片策略。

与 AstrBot 内置功能共存

插件先于核心分段/TTS/转发执行；这些开关可以保留原生行为。

渲染设置

浏览器路径留空时自动探测系统 Chromium 或 Playwright 自带浏览器。

修改后点击保存；配置会立即生效。
